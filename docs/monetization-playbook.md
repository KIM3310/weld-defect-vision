# Monetization Playbook - weld-defect-vision

This file is a commercial planning artifact, not a guarantee of revenue. Use it to make the repository legible as a sellable product, pilot, workshop, license, or proof-of-value package.

## Commercial Lane

- **Lane:** B2B industrial AI validation
- **Primary buyer:** Manufacturing quality teams, welding inspection groups, industrial AI, and edge deployment reviewers.
- **Revenue wedge:** YOLOv8 defect workflow with model governance, serving, and operator-readable evidence.

## Offer Ladder

1. **Inspection PoC** - pricing hypothesis: $5k-$15k PoC
2. **Model validation study** - pricing hypothesis: $20k-$70k validation
3. **Edge-serving readiness assessment** - pricing hypothesis: $3k-$15k/month model ops support

## Acquisition Channels

- Industrial AI demos
- Quality-inspection case study
- Edge deployment checklist

## Proof Gates Before Selling

- pytest passes
- Model card exists
- API detection path is documented

## Risk Boundaries

- Human inspection required
- Site-specific validation
- No production acceptance without criteria

## 30/60/90 Day GTM

- **30 days:** Publish model-card walkthrough
- **60 days:** Create sample defect report
- **90 days:** Offer validation sprint

## Metrics That Matter

- mAP/recall by defect
- False-negative review
- Operator review time

## Positioning Note

Lead with the specific operational pain, then show the runnable proof, then offer a narrow pilot. Do not pitch the repository as a vague app; pitch it as a concrete workflow with evidence, risk boundaries, and a next buying step.
