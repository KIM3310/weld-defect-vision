Privacy Policy

Last updated: 2026-07-28

The public Weld Defect Vision demo uses synthetic weld inspection examples for industrial validation discovery. It does not request uploads, customer images, production defect records, account credentials, or regulated data.

Static hosting and security layers may process basic request metadata such as IP address, user agent, request time, and requested path for delivery, abuse prevention, and reliability.

Private industrial validation discovery requires an owner-approved intake path before customer datasets, inspection images, defect logs, or confidential acceptance criteria are shared.
